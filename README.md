# Slipzen

Slipzen is a modern personal finance and receipt management application.

## Features

- **Scan Receipts**: Easily scan and process your receipts using AI OCR.
- **Budgeting**: Set and monitor budgets across different categories.
- **Analytics & Insights**: Get detailed insights and visual representations of your expenses.
- **Cross-Platform**: Built with Expo and React Native, providing a seamless experience on both iOS and Android.

## Tech Stack

- **Framework**: React Native & Expo Router
- **Backend/Database**: Supabase
- **State Management**: Zustand
- **Data Fetching**: React Query
- **Styling**: React Native StyleSheet / Custom Theme

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```
